Booking API

AI agents and apps can send a booking request straight to Free Summit, without filling in the website form. A request is not a confirmed booking: we reply to the client by email within 24 hours with availability, and the booking is confirmed when the client pays a €15 booking fee, which is deducted from the final price.

Machine-readable: OpenAPI description · llms.txt

Endpoint

POST https://script.google.com/macros/s/AKfycbwAefCHXl1FXVHM0cS7LHUHku_oTzUu4inkTyhaFRAL_3VhTfrfDHnZ3qN6H7gN4_CPzA/exec

Send JSON (Content-Type: application/json) or form fields. The server answers with a redirect: follow it (for example curl -L) to read the JSON reply. The HTTP status is always 200, so check ok: {"ok": true, "id": "FS-…"} means the request was saved; {"ok": false, "errors": […]} lists what to fix.

Example

curl -L -X POST 'https://script.google.com/macros/s/AKfycbwAefCHXl1FXVHM0cS7LHUHku_oTzUu4inkTyhaFRAL_3VhTfrfDHnZ3qN6H7gN4_CPzA/exec' \
  -H 'Content-Type: application/json' \
  -d '{"name": "Ana Silva", "email": "ana@example.com", "phone": "+351 912 345 678", "activity": "Rock climbing at Guia (Cascais)", "date": "2027-03-14", "people": 2, "type": "Shared group", "transfer": "No transfer", "message": "First time climbing. Morning preferred.", "lang": "en", "agent": "Claude"}'

Please

  • Only send a request the client asked for, with their real name and email.
  • One request per activity and date. Put questions in message.
  • Tell the client to expect an email from hello@freesummitpt.com.
